## Tecnologias

O cartão do AutoFlow RPA mantém a galeria de telas e oferece o botão **Vídeo · 28 s**, com apresentação em capturas reais, controles nativos e legendas em português. O MP4 é carregado ao escolher o vídeo, preservando o carregamento inicial. Os dados e envios de cobrança apresentados são fictícios.

- Next.js (App Router) e React
- TypeScript
- Tailwind CSS
- lucide-react (ícones)
- Deploy na Vercel

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.
